# Tandem

**Русский** · [English](README.md)

**Claude Code и Codex работают над одной задачей вместе.**

Две модели с разными слепыми пятнами в одном терминале. Любая может позвать
другую за тем, чего у неё нет: за ревью, за взглядом с другой стороны, за
задачей, которую можно снять с рук.

![Claude просит Codex оспорить решение о кэше, и Codex находит реальный баг](assets/demo/demo.gif)

<sub>Настоящий обмен из этого репозитория, не постановка — [полный транскрипт и коммит, которым он закончился](docs/example-debate.ru.md).</sub>

| Claude → Codex | Codex → Claude |
| --- | --- |
| Задать вопрос | Задать вопрос |
| Отревьюить текущие изменения | Раскритиковать план до применения |
| Оспорить решение | Передать задачу обратно в Claude Code |
| Делегировать задачу в фон | Пользоваться инструментами Claude Code |
| Сгенерировать изображение | Дотянуться до ваших MCP-серверов через проброс |

**Ни одного API-ключа.** Всё работает на подписках Claude и ChatGPT, которые у вас уже есть.

```
/plugin marketplace add VlDubr/tandem
/plugin install tandem@tandem
```

Ещё две команды и проверка готовности — в разделе [Установка](#установка).

<sub>Плагин Claude Code, а не отдельный воркспейс рядом с ним — и
единственный, где движение идёт в обе стороны: Codex может позвать Claude в
ответ и дотянуться через него до ваших MCP-серверов. Сверено с аналогами
2026-08-28.</sub>

## Для чего это

**Поймать то, что пропустил Claude.** Claude пишет, Codex независимо ревьюит диф, Claude чинит. Модель, проверяющая собственную работу, приносит с собой и собственные слепые пятна.

**Получить второе мнение о решении.** `/tandem:challenge схема ретраев` — GPT защищает противоположную сторону и называет режим отказа, который никто не учёл. Обмен на гифке выше — как раз такой случай, и GPT оказался прав.

**Отдать скучную половину.** Отправить падающие тесты в Codex фоном и продолжить заниматься фичей. Вернуться за диагнозом.

**Дать Codex посоветоваться с Claude.** Обратный мост: GPT, работая над задачей, может спросить мнение Claude и воспользоваться его инструментами. Именно этого направления нет больше нигде.

## Зачем

У двух моделей разные слепые пятна. Решение, которое одна считает очевидным, вторая нередко разносит в пух и прах — и часто по делу. Но чтобы этим пользоваться, обычно приходится вручную гонять текст между двумя окнами, теряя контекст на каждом переносе.

Tandem убирает этот перенос. Claude, наткнувшись на спорное архитектурное решение, сам спросит мнение GPT — без вашей команды. GPT, разбираясь в незнакомом коде, сам обратится к Claude. Вы видите обе позиции и точку расхождения.

```
                              ┌──────────────┐
   /tandem:ask          │              │        claude_ask
   /tandem:review   ───►│    Codex     │◄───    claude_critique
   /tandem:delegate     │    Bridge    │        claude_task
   Claude Code            ◄───│              │───►    Codex CLI
   результаты                 └──────────────┘        проброшенные MCP
```

## Возможности

### Ревью кода

| | |
|---|---|
| **Обычное ревью** | GPT разбирает текущие изменения: блокеры, баги, гонки, необработанные ошибки — с указанием файла и строки |
| **Состязательное ревью** | Не ищет опечатки, а оспаривает решение: какие допущения не проверены, какой сценарий отказа упущен, есть ли путь проще |

### Делегирование задач

Опишите баг — GPT сам разберётся в причине, внесёт минимальную правку и запустит тесты. Работает в фоне: запустили и продолжаете свою работу.

```
/tandem:delegate тесты auth_spec начали падать после мержа main, разберись
/tandem:status      # идёт?
/tandem:result      # что получилось
/tandem:cancel      # передумал
```

### Видно, что происходит

Долгие вызовы больше не упираются в слепой таймаут. Codex стримит свою активность — рассуждения, команды, правки файлов, поиск, — а плагин превращает это в читаемую ленту:

```
/tandem:progress

  · спрашивает: почему повторная доставка вебхука списывает деньги дважды
  · размышляет: Разбираю схему ретраев вебхука
  · запускает: rg -n retry src/
  · ищет в вебе: idempotency key payment webhook
  · размышляет: Проверяю гонку при повторной доставке
```

Плагин отдаёт эту ленту как `notifications/progress` ещё во время вызова, поэтому клиент, который их отрисовывает, может показывать шаги по мере появления. Claude Code сейчас собирает их в блок вывода вызова инструмента, а не в живую ленту, и сам ответ модели приходит целиком в конце: видно, чем Codex занят, но прочитать ответ по мере написания или перебить его на полуслове нельзя.

Если синхронный `codex_ask` не укладывается в отведённое время, он не падает и ничего не теряет: та же самая задача продолжает идти тем же процессом в фоне, а вы получаете её id вместе со всем, что модель успела сделать. Отмена вызова в Claude останавливает и Codex.

Оговорка: наружу Codex отдаёт сводки размышлений, а не полные рассуждения. При настройке `reasoning_summary = auto` сводок может не быть вовсе — поставьте `detailed`, если лента нужна подробной.

### Разговор с моделями Codex

Модели Codex доступны как отдельные собеседники: тред сохраняется, модель помнит предыдущие ходы.

```
/tandem:use gpt-5.6-sol
/tandem:chat --chat retry разбери схему ретраев в src/webhook
/tandem:chat --chat retry а что будет при повторной доставке?
```

Одно имя чата — один непрерывный тред. Модель и уровень reasoning задаются на первом ходе и дальше повторяются сами. `--write` разрешает модели менять файлы, по умолчанию доступ только на чтение. Список разговоров — `codex_chats`.

Ограничение честное: плагин не может добавить модели Codex в `/model` Claude Code — API для регистрации провайдера моделей нет. Обращение идёт через команду `/tandem:chat` или агента `tandem:gpt-chat`.

### Совместная работа двух моделей

```
/tandem:ask     стоит ли выносить этот кеш в Redis или хватит in-memory
/tandem:debate  схема ретраев для платёжного вебхука
```

`/tandem:debate` проводит структурированный спор в несколько кругов: Claude формулирует позицию, GPT её оспаривает, Claude отвечает на сильнейшее возражение. В конце — что признали обе стороны, где остались разногласия и какой эксперимент их разрешит. Согласие не изображается: два расходящихся мнения полезнее одного усреднённого.

### Исследование, мозговой штурм и свободное взаимодействие

```text
/tandem:research --session cache сравните стратегии кеширования для проекта
/tandem:brainstorm --session onboarding найдите способы упростить онбординг
/tandem:custom --session migration поручите GPT независимую оценку рисков миграции
/tandem:research --session cache --continue исследуйте оставшийся вопрос согласованности
```

Основная модель в IDE управляет диалогом и сама участвует в анализе. Автономного фонового цикла между моделями нет. Исследование развивает и проверяет гипотезы. Мозговой штурм разделяет независимую генерацию идей, оценку и синтез. Свободный режим позволяет основной модели самой формулировать вопросы и ограниченные поручения на чтение. Промежуточные вклады подписываются именами моделей; итог сохраняет неразрешённые разногласия.

Оба направления используют один протокол: `codex_collaborate` и `claude_collaborate`. У именованной сессии **шесть вызовов второй модели на этап**, включая неудачи и отмены. Успешный синтез закрывает этап досрочно. Продолжение требует `action: "extend"`, сводку и `confirm: true` после явного запроса пользователя. Сервер проверяет лимит этапа, но флаг подтверждения — заявление ведущей модели, а не аутентифицированное согласие человека. Это не лимит токенов или стоимости.

Сессии переживают перезапуск моста. `action: "status"` возвращает состояние и получает готовый результат Codex без повторного запуска; `action: "cancel"` отменяет текущий раунд. Вызов Claude ожидает завершения; Codex может вернуть `pending` с идентификатором задачи. Ведущая модель должна опрашивать эту задачу, а не отправлять замену. После продления второй модели передаются сводка и новый этап; полный старый диалог остаётся локально. Ответы длиннее 16 000 символов явно помечаются как сокращённые; полный текст находится в `state_file`.

Такие сессии **никогда не дают права записи**. Для правок используется существующее отдельное делегирование с разрешением пользователя. Claude получает только Read/Grep/Glob; Codex — песочницу read-only с отключёнными настроенными MCP-серверами. Рекурсивные обращения к мосту блокируются. Совместная работа с Codex несовместима с `bypass_sandbox`: нужно исправить песочницу и выключить обход, а не молча убирать изоляцию. Режим не обещает веб-доступ или произвольные внешние MCP-инструменты; проверенные источники может передать основная модель.

Диалоги сохраняются вне репозитория в папке `collaborations` каталога данных плагина, отдельно для канонического рабочего каталога и вызываемой модели. Они содержат запросы и ответы; автоматического срока удаления нет. Не передавайте учётные данные и чувствительные материалы: read-only не является фильтром секретов. Существующие `/tandem:chat`, `/tandem:ask`, `/tandem:debate` и делегирование работают по-прежнему.

### Генерация изображений

```
/tandem:image --ar 16:9 --res 2K баннер для лендинга, тёмный фон, изометрия
/tandem:image --ref designs/palette.png иконка настроек в стиле референса
```

Рисует gpt-image-2 через встроенный инструмент Codex — на вашей подписке ChatGPT, без API-ключа. После генерации Claude **открывает картинку и смотрит на неё**: сверяет с выписанными заранее критериями и при расхождении правит промпт и генерирует заново. Ответ «успешно» от модели ничего не говорит о том, что нарисовано.

### Двусторонний мост

После `/tandem:setup --link-back` у GPT появляются свои инструменты:

- **`claude_ask`, `claude_critique`** — спросить мнение Claude, попросить раскритиковать план до его применения
- **`claude_collaborate`** — исследование, мозговой штурм или свободное поручение на чтение с памятью диалога под управлением GPT
- **`claude_task`** — поручить задачу Claude Code со всеми его инструментами
- **Проброс MCP** — инструменты ваших MCP-серверов (трекер, база, документация) становятся доступны GPT напрямую

## Требования

- **Claude Code** 2.1.154 или новее
- **Node.js** 20.11+ (или 21.2+)
- **Codex CLI** с подпиской ChatGPT — годится любая, включая Free

## Установка

```bash
npm install -g @openai/codex   # если Codex ещё не стоит
codex login                    # вход через аккаунт ChatGPT, OAuth
```

Дальше в сессии Claude Code:

```
/plugin marketplace add VlDubr/tandem
/plugin install tandem@tandem
/reload-plugins
/plugin enable tandem
```

Проверить, что всё на месте:

```
/tandem:setup
```

Команда покажет версию Codex, состояние авторизации, доступные модели и каталог для изображений. Если чего-то не хватает — скажет, чего именно.

> Плагин ставится **выключенным**. Он расходует лимиты вашей подписки ChatGPT и расширяет набор доступных инструментов, поэтому включение — осознанное действие, а не побочный эффект установки.

## Настройка

При включении Claude Code спросит несколько значений — все необязательные:

| Параметр | Что задаёт |
|---|---|
| `language` | Язык сообщений и промптов, уходящих в Codex: `en` (по умолчанию) или `ru`. Модель отвечает на языке промпта, поэтому настройка задаёт и язык её ответов. Команды и агенты всегда английские |
| `default_model` | Модель Codex по умолчанию. Список — `/tandem:models` |
| `default_effort` | Уровень reasoning: `none`, `low`, `medium`, `high`, `xhigh`, `max`. Точный набор зависит от модели — см. `/tandem:models` |
| `review_backend` | Транспорт ревью: по умолчанию `exec`; `app-server` явно включает нативный reviewer с безопасным fallback до принятия запроса |
| `reasoning_summary` | `detailed` — подробные сводки размышлений в ленте, `auto` — как решит Codex (сводок может не быть) |
| `progress_notifications` | Показывать ход работы прямо во время вызова. Выключите, если ваша сборка Claude Code рвёт соединение на таких уведомлениях — см. «Если что-то пошло не так» |
| `max_parallel_jobs` | Сколько задач Codex можно выполнять одновременно (по умолчанию 4; `0` снимает предел) |
| `job_timeout_minutes` | Через сколько убивать зависшую фоновую задачу (по умолчанию 30) |
| `image_output_dir` | Куда складывать изображения (по умолчанию `assets/generated`) |
| `image_timeout_minutes` | Таймаут генерации картинки (по умолчанию 15) |
| `bypass_sandbox` | Аварийный обход сломанной песочницы Codex. По умолчанию выключен — см. «Если что-то пошло не так» |

### Строка состояния

Чем заняты модели Codex прямо сейчас, можно вывести в строку состояния Claude Code. Плагин её не прописывает сам: `statusLine` один на всю установку, и затирать чужую настройку молча нельзя. Добавьте в `settings.json`:

```json
"statusLine": {
  "type": "command",
  "command": "node ~/.claude/plugins/cache/<маркетплейс>/tandem/<версия>/scripts/statusline.mjs"
}
```

Когда задач нет, строка пуста.

### Обратный мост GPT → Claude

По умолчанию выключен. Включается одной командой:

```
/tandem:setup --link-back
```

Она добавляет MCP-сервер в `~/.codex/config.toml`. После перезапуска Codex у GPT появляются `claude_ask` и `claude_critique`. Отключить: `/tandem:setup --unlink-back`.

Делегирование в обратную сторону включается отдельно, с явным потолком инструментов:

```
/tandem:setup --allow-task --task-tools Read,Grep,Glob
```

### Проброс MCP-инструментов

Посмотреть, что подключено к Claude, и пробросить нужное:

```
/tandem:setup --expose-list
/tandem:setup --expose tracker --tools list_issues,create_issue
/tandem:setup --unexpose tracker
```

Пробрасывается только явно перечисленное. Инструмент, не попавший в `--tools`, для GPT просто не существует.

## Команды

| Команда | Что делает |
|---|---|
| `/tandem:review [--base main] [--now]` | Ревью текущих изменений |
| `/tandem:challenge <что оспорить>` | Состязательное ревью: оспаривает дизайн |
| `/tandem:delegate <задача>` | GPT исследует и чинит сам, с правом менять файлы |
| `/tandem:progress [id]` | Чем модель занята сейчас: рассуждения, команды, правки файлов |
| `/tandem:status [id]` | Статус фоновых задач |
| `/tandem:result [id]` | Результат завершённой задачи |
| `/tandem:cancel [id]` | Отмена выполняющейся задачи |
| `/tandem:ask <вопрос>` | Второе мнение от GPT прямо сейчас |
| `/tandem:chat [--model M] [--chat имя] [--write] <сообщение>` | Разговор с моделью Codex, тред помнит предыдущие ходы |
| `/tandem:use [модель] [--effort уровень]` | Модель Codex по умолчанию для репозитория |
| `/tandem:debate <тема>` | Спор Claude ↔ GPT в несколько кругов |
| `/tandem:research [--session имя] [--continue] <тема>` | Совместное исследование с сохраняемыми этапами и проверкой гипотез |
| `/tandem:brainstorm [--session имя] [--continue] <проблема>` | Независимая генерация идей, их оценка и выбор решения |
| `/tandem:custom [--session имя] [--continue] <цель>` | Основная модель сама выбирает вопросы и поручения второй модели на чтение |
| `/tandem:image <описание>` | Изображение gpt-image-2 с проверкой результата |
| `/tandem:models [--refresh]` | Модели, реально доступные в этом Codex |
| `/tandem:setup [флаги]` | Диагностика, обратный мост, проброс инструментов |

Слэш-команды — не единственный вход. Claude вызывает те же возможности сам, когда они уместны по контексту. Есть и субагенты: `@tandem:gpt-advisor` для второго мнения, `@tandem:gpt-delegate` для передачи работы, `@tandem:gpt-chat` для разговора с конкретной моделью Codex, `@tandem:image-smith` для длинного цикла генерации с проверкой.

## Модели

```
/tandem:models
```

Список не зашит в плагин, а запрашивается у самого Codex — модели снимаются с обслуживания, и зашитые списки устаревают молча. Опечатка в имени отклоняется сразу, со списком доступных вариантов.

Модель задаётся на трёх уровнях: флагом конкретной команды, настройкой плагина или через `model` в `~/.codex/config.toml`.

## Безопасность и приватность

**Ваш код уходит в OpenAI.** Ради этого мост и нужен, поэтому лучше сказать прямо, а не спрятать в конце раздела. Всё, что вы через него отправляете, — промпт, диф для ревью и любой файл, который Codex решит прочитать по ходу работы — покидает вашу машину и уходит на серверы OpenAI по вашей подписке ChatGPT. В обратную сторону то же самое: ответы Claude через обратный мост и результаты проброшенных MCP-инструментов попадают в контекст Codex и уходят вместе с ним. Если работодатель запрещает отправлять исходники в OpenAI — не ставьте плагин.

**Секретные файлы вырезаются из дифа для ревью.** `.env`, `.npmrc`, `.netrc`, приватные ключи, хранилища ключей и подобное попадают в диф только именем: сам факт изменения виден, содержимое — нет. Обычные изменения рядом при этом сохраняются, и ревью остаётся осмысленным.

**Токенов плагин не хранит.** OAuth выполняет `codex login`, плагин работает поверх уже существующей локальной сессии Codex CLI — той же, что и при прямом запуске `codex`.

**Ничего не пробрасывается по умолчанию.** Обратный мост, делегирование и проброс MCP-инструментов выключены, пока вы их явно не включите. Список разрешённых инструментов — потолок, который GPT может сузить, но не расширить.

**Чужие секреты не копируются.** При пробросе MCP-сервера переменные окружения сохраняются только как ссылки `${VAR}`, раскрываемые при запуске. Литеральные значения плагин не сохраняет и предупреждает о них.

**Файлы состояния** создаются с правами `0600` в каталоге `0700`.

## Стоимость

Расход идёт по лимитам **подписки ChatGPT**, отдельно от подписки Claude. Никаких API-ключей и оплаты по токенам. Генерация изображений тоже укладывается в подписку.

Учтите: `/tandem:image` занимает 4–6 минут — Codex сначала рассуждает и только потом вызывает инструмент. При 4K дольше. Это нормально, а не зависание.

## Если что-то пошло не так

**«Модель не принимает уровень усилий»** — набор уровней зависит от модели. `minimal` принимают только модели прошлых поколений, `gpt-5.6` и новее отвергают его ошибкой API. Посмотрите доступные уровни командой `/tandem:models` — они показаны рядом с каждой моделью, — и возьмите `low` или выше.

**`failed to load models cache: missing field ...` в логах Codex** — рассинхрон формата внутреннего кэша самого Codex, на работу не влияет. Плагин отфильтровывает эту строку из сообщений об ошибках, чтобы она не маскировала настоящую причину.

**`MCP error -32000: Connection closed` на длинных вызовах** — у части сборок Claude Code получение `notifications/progress` закрывает соединение с MCP-сервером ([anthropics/claude-code#47378](https://github.com/anthropics/claude-code/issues/47378), [#53617](https://github.com/anthropics/claude-code/issues/53617)). Выключите настройку `progress_notifications` — лента исчезнет, всё остальное продолжит работать. Отрисовка ленты в свёрнутом виде инструмента появилась в Claude Code 2.1.153.

**На Windows: `orchestrator_helper_launch_failed` / `program not found` либо необъяснимое «user cancelled MCP tool call»** — не запустилась песочница Codex. Наружу это выходит как отказ MCP-инструмента или отмена пользователем, поэтому читается как мёртвый мост, хотя мост исправен. Обычная причина — установка Codex собрана из разных версий: CLI одной, а хелперы в `~/.codex/.sandbox-bin` другой. Запустите `/tandem:setup` — он сверяет версии и называет расхождение. Решение — переустановить Codex (`npm install -g @openai/codex`). Как временный обход можно включить настройку `bypass_sandbox`, но тогда Codex выполняет команды без изоляции.

**`unexpected argument '--...'`** — набор флагов `codex exec` менялся между версиями. Первое, что стоит сделать, — обновить плагин: сборку, которая передаёт флаг безусловно, сбросом кэша не вылечить. Если после обновления ошибка осталась, значит устарел кэш определения флагов — он привязан к версии бинаря, но его можно удалить вручную: `exec-caps.json` в каталоге данных плагина.

**Диагностика окружения** — `/tandem:setup` показывает версию Codex, состояние авторизации, каталог моделей и состояние обратного моста.

## Ограничения

- Проброс MCP работает только со **stdio**-серверами. HTTP/SSE с собственной OAuth-авторизацией проще подключить к Codex напрямую.
- Референсы для изображений — только **локальные файлы**, URL встроенный инструмент не принимает.
- Встроенные инструменты Claude (Read, Edit, Bash) намеренно не пробрасываются: у Codex есть свои эквиваленты.
